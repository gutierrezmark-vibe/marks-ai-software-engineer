Bond Stepped Fretboard Profile Tool

Sawtooth fret-step profile — single scale or multiscale (fanned) with a fully adjustable perpendicular fret. 2D profile for Fusion import; STEP is a true B-rep solid; STL is the mesh fallback.

Scale & Frets
Scale type

MULTISCALE
The perpendicular fret is held square to the centerline. Nut = frets fan out toward the bridge. A middle fret squares that fret (both ends fan). Bridge = the fan reverses, widest at the nut and converging toward the bridge. Treble = high-E edge (shorter); bass = low-string edge (longer).
Step Geometry
Each step is a right triangle: a vertical wall at the fret position (the string-contact edge) rising by the fret contact height, then a straight slope back down to the base of the next fret's wall. Base thickness is measured to the low point (trough) of the sawtooth.
Board Taper (STEP / STL)
Width runs from the nut width at fret 0 to the heel width at the end of the board, centered on the length axis. For multiscale, the treble edge is the back face and the bass edge is the front face; the solid lofts between them. Set nut = heel and single scale for a plain parallel extrusion.
Fingerboard Radius (STEP / STL)
FLAT
RADIUSED
The radius is a cylinder whose axis runs along the neck, so the curve is across the width; the side profile is unchanged. The crown (center) keeps the full base thickness and the edges thin out by the sagitta. Minimum 7.25 in (184.15 mm). Higher facets = smoother arc, larger mesh. Note: in the STEP solid the radius is faceted into this many planar strips (still a real solid, just polygonal in section). Flat mode STEP is mathematically exact.
Fret position table
Flat (unradiused) Bond-style stepped board. No traditional metal frets, no compound radius. The nut region (before fret 1) is flat at trough height; there's no zero-fret step. Single scale: one 2D side profile drives everything. Multiscale: the treble and bass edges are two different profiles, so the SVG/DXF/PDF (which are inherently single-scale 2D views) are disabled — the STEP and STL loft between the two edges and are the multiscale deliverables.

Side Profile  — single: extrude across width. multiscale: preview shows both edges; use the STEP.

STEP export ready. The STEP file is a watertight MANIFOLD_SOLID_BREP — open it in Fusion with File → Open (or Insert → Insert Derive) and it arrives as a real BRepBody you can fillet, boolean and machine. No mesh conversion involved.
