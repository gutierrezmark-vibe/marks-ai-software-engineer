## Stepboard — Bond-style stepped fretboard designer

**Use it in your browser:** https://gutierrezmark-vibe.github.io/marks-ai-software-engineer/fretboard-tool/

Design a stepped fingerboard in the style of the Bond Electraglide, where each fret is the sharp edge of a step instead of a fret wire. Set the scale (single or multiscale/fanned), fret count, number of strings, nut and heel widths, step height, radius and step direction, then export:

- **STEP** — a true solid with smooth curved surfaces, ready for Fusion 360 or CNC quoting
- **STL** — a watertight mesh for 3D printing
- **SVG / DXF** — the side profile for CAD/CAM
- **PDF** — the side profile at 1:1, a dimensioned top-view drawing for machine shops, and a 1:1 top-view template that prints across Letter pages

Everything runs in the browser from a single file, [`fretboard-tool/index.html`](fretboard-tool/index.html). You can also download that file and open it locally.
